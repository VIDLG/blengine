# Image declarations and historical evidence

Only `multifunction-rf-v2-{a,b}.json` are maintained image declarations. Select their matching build/exported contracts in `../contracts/` and profiles in `../profiles/` for current RF gates; declarations alone never prove an installed image.

The v1 JSON declarations remain byte-for-byte at these original paths solely to preserve historical report links. They are the unique evidence copies, not live defaults or a compatibility lane. Archived implementation/tests may inspect them offline; maintained live admission rejects v1 contracts. Ordinary runs do not flash or reset firmware.
