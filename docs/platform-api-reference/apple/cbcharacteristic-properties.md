# properties

The properties of the characteristic.

```
var properties: CBCharacteristicProperties { get }
```

## Discussion

The properties of a characteristic determine the access to and use of the characteristic’s value and descriptors. For a list of the possible values representing the properties of a characteristic, see [`CBCharacteristicProperties`](/documentation/CoreBluetooth/CBCharacteristicProperties).
