# CBAdvertisementDataIsConnectable

A Boolean value that indicates whether the advertising event type is connectable.

```
let CBAdvertisementDataIsConnectable: String
```

## Discussion

The value for this key is an <doc://com.apple.documentation/documentation/Foundation/NSNumber> object. You can use this value to determine whether your app can currently connect to a peripheral.
